Role Feature Acceptance Matrix

This additive change adds a Role Feature Center to each authenticated workspace without replacing existing routes or APIs.

Administrator — 10 capabilities

  1. User and role management
  2. Platform health
  3. YARA library management
  4. Ruleset imports and updates
  5. Model artifact readiness
  6. Global scan monitoring
  7. Audit event review
  8. Platform analytics
  9. Threat notifications
  10. Static evidence inspection

SOC Team Member — 10 capabilities

  1. Threat overview
  2. Live alert triage
  3. Incident queue, assignment and status
  4. Scan activity
  5. Threat timeline
  6. Response checklist
  7. Shift handover
  8. Operational analytics
  9. Notifications
  10. Evidence detail

Security Analyst — 10 capabilities

  1. Static file scanner
  2. Hash and metadata review
  3. YARA match explorer
  4. Rule explanations and library references
  5. ML assessment availability/output
  6. Evidence comparison
  7. Risk component review
  8. Investigation reporting
  9. Historical comparison
  10. Investigation analytics

Researcher — 10 capabilities

  1. Sample record explorer and label annotations
  2. Category/family research notes
  3. Model-vs-YARA comparison
  4. Feature distribution
  5. False-positive review support
  6. False-negative review support
  7. Detection trend analysis
  8. ML output/availability review
  9. Research export
  10. Reproducibility notes

Ten chart types

  1. Line trend
  2. Bar comparison
  3. Donut composition
  4. Weekday/hour heatmap
  5. Scatter relationship
  6. Stacked bar over time
  7. Triage funnel
  8. Histogram
  9. Radar profile
  10. Treemap

Limitations: these links expose existing workflows; this page does not turn local prototype workflows into enterprise SIEM/ITSM features. Chart values use stored scan records. Runtime telemetry, complete YARA signatures and compatible model inference remain environment-dependent. See VERIFICATION_REPORT.md.
