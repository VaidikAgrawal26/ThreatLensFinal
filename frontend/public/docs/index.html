Important limitations

  • No YARA rules are bundled by default; install a reviewed ruleset before relying on signature matching.
  • The configured Random Forest and matching schema are present, but its partial static predictions are not independently validated for live accuracy.
  • Static triage scores are not calibrated probabilities; no-match does not prove safety.
